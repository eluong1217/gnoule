# gnoule

Personal portfolio website built with SvelteKit, TypeScript, and vanilla CSS.

## Features

- Project showcase with expandable cards
- Research section with links to articles, demos, and source code
- Theme toggle with light and dark mode
- Animated hero section with custom visual elements
- Responsive layout for desktop and mobile

## Tech Stack

- SvelteKit 5
- TypeScript
- Vanilla CSS
- npm
